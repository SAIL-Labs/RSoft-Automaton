Solidified pigtail functionality in RSoft.

To simulate pigtail bundles:
1) Populate the keyword "add_cladding_to_cores" in simulation_val with an array of numbers pertaining to the number of cores, 0-indexed.
i.e. if you want to add cladding to every core in a 7cPL: simulation_val["add_cladding_to_cores"] = [0,1,2,3,4,5,6]

2) Whether you are simulating core diameters etc YOU NEED TO RUN FEMSIM ON THE IND FILE TO GENERATE THE FEMSIM FILES USED!!!! This should always be done when the properties of your lantern change to ensure you are simulating a perfect lantern.

3) If you don't want to specify specific femsim files, set simulation_val["fixed_fem_file"] = False

If you want to simulate weird geometries, i.e. a lantern missing some cores:
1) Populate the keyword "skip_core" in simulation_val with an array of numbers pertaining to the specific core(s) you'd like to skip, 0-indexed.
i.e. if you want to skip the centre core in the standard 7cPL: simulation_val["skip_core"] = [6]

If you want to simulate with a specific femsim file. set simulation_val["fixed_fem_file"] = True and specify the file with simulation_val["port_mon_file"].

Added functionality to test industry standard Neff values for the mode selective core. Set the flag simulation_val["industry_neff_values"]=True and specify the directory to the text file containing the values with simulation_val["industry_neff_file"].

Modified how core delta is treated. Now, prior ranges must consider Neff instead of core delta (i.e. core_delta + background). This is what is reported and is getter than using core_delta since there is ambiguity between either the background or the cladding (i.e. core_delta +_ background or core_delta + cladding).

Bug fixes/changes:

- changed how the results are saved. Simultaneous simulations are now saved in the same folder dubbed BP_Simulation_number for better results organisation, but also to reduce the character limit for the folder name. Without this, the folder name length will extend beyond the standard 260-character length in Windows without activating a setting in Group Policy.
